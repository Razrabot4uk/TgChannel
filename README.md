# TgChannel

Простой релей для Telegram, который перенаправляет сообщения пользователей в ваш личный чат и позволяет отвечать им прямо из ответов.

## Настройка
1. Создайте бота через BotFather и получите токен.
2. Узнайте свой `chat_id` (можно через @userinfobot или любой другой способ).
3. В файле `bot.py` заполните реальные значения в объекте `config`:
   ```python
   config = BotConfig(token="<токен_бота>", owner_chat_id=<ваш_chat_id>)
   ```
4. Установите зависимости:
   ```bash
   pip install python-telegram-bot==20.8
   ```

## Запуск
```bash
python bot.py
```
Бот будет пересылать в ваш чат все пользовательские сообщения (текст, фото, видео, голосовые, документы, стикеры и другие типы) и отправлять ответы адресату, если вы сделаете реплай на пересланное сообщение.
